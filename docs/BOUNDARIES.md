The maintained entrypoint is python -m fbsim_paper. All routes read external immutable manifests and write only to new disposable output trees. Scientific function bodies, input panels, normalization and uncertainty methods are retained. Starsim and Micropolis numerical scoring imports the benchmark; paper scripts own selection/normalization/aggregation. FreeCiv reporting consumes existing per-item scores. The complete original coauthor source remains recoverable outside this package. No manuscript mutation, simulator launcher, provider request or private prompt export is a supported paper workflow. Assets preserve reporting dependencies, not a promise that every legacy helper is runnable independently. See MIGRATION_GAPS.md for excluded workflows.
